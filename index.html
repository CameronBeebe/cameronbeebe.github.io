01 · A plan needs a way into the world

Same starting point. Same goal. Same planner. The hollow dot is the imagined position; the solid dot is the actual object. Get the real dot to the goal.

Click either world to move the goal for both. Change the current and watch: an intention moves the vat’s imagined object; tools move the harness’s real one.

Brain in a vat · intentions only

Harness · intentions → actions → feedback

Hollow dot = imagined · solid dot = actual · square = goal. When imagined and actual positions agree, they appear as one dot.

What is this modeling?

Both planners predict motion in still water. The real world has a current they initially do not know about. Tools apply the planner’s movement command; feedback supplies the actual position so the next command can correct the error. Switches affect only the harness.

The vat receives a fresh position only when you press its update button. That corrects its picture, but gives it no actuator. The visitor can see both realities; the vat cannot.

This is a scripted control-system analogy, not an LLM simulation. The shaded area marks the goal region; it is not a physical force pulling the object. Success requires an actual world change. Changing the goal starts a new attempt from the current positions.
